# Flipper Zero Script Pack (Safe & Legal)

This pack contains **non-abusive** Flipper Zero BadUSB scripts intended for personal automation and lab/demo use.

## Important
- Only run these on devices you own or are explicitly authorized to test.
- Review every script before use.
- Keyboard layouts differ by locale; adjust for your target machine.

## Included scripts

### Windows
1. `badusb/windows_open_notepad.txt` - Opens Notepad.
2. `badusb/windows_todo_template.txt` - Opens Notepad and writes a TODO template.
3. `badusb/windows_open_calculator.txt` - Opens Calculator.
4. `badusb/windows_copy_ipconfig.txt` - Runs `ipconfig` and keeps the window open.

### Linux
5. `badusb/linux_open_terminal.txt` - Opens a terminal (common shortcut).
6. `badusb/linux_system_snapshot.txt` - Opens terminal and runs basic read-only info commands.

### macOS
7. `badusb/macos_open_terminal.txt` - Opens Terminal via Spotlight.
8. `badusb/macos_system_snapshot.txt` - Runs basic read-only info commands in Terminal.

### Cross-platform typing helpers
9. `badusb/type_email_template.txt` - Types a generic support email template.
10. `badusb/type_meeting_notes_template.txt` - Types a meeting-notes template.
11. `badusb/type_bug_report_template.txt` - Types a bug report template.
12. `badusb/type_markdown_checklist.txt` - Types a markdown checklist.

## Usage
1. Copy these `.txt` files to your Flipper Zero `badusb/` folder.
2. On Flipper: **Bad USB** app -> choose script -> run.
3. Ensure target machine is focused on the correct app/input field.

## Notes
- These are starter templates. Tweak delays and shortcuts as needed.
- Scripts that open terminals are OS-shortcut dependent.
